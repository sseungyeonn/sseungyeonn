## 💼 Experience

### 국가데이터처 인구추계팀 · 청년인턴 &nbsp;<sub>`2026.03 – 2026.08`</sub>

**AI 기반 인구추계 신사업 (출생 · 사망 · 국제이동)** · `R` `Python` `LSTM` `Transformer`
- 코호트 요인법(통계적 방식)으로 추계해 온 팀에서 **올해 처음 시도한 AI 인구추계 사업**을 이어받아 출생 · 사망 · 국제이동 3개 모델의 5년 · 10년 예측을 담당
- 주석과 맞지 않고 한 파일에 뒤섞여 있던 기존 코드를 **주석과 일치시키고 단계별로 정리**
- 기존 분석과 현행 기준의 **연령 구간이 달라 데이터를 다시 정제**하고, 지표마다 다른 관측 기간 · 연령 · 공변량을 맞춰 예측 기간을 확장
- RMSE로 오차를 비교하며 **오차의 원인이 공변량인지 파라미터인지 나눠서 점검** — 국제이동이 공변량에 특히 민감함을 확인
- 새 연도 자료를 반영해 학습 · 검증 구간을 1년씩 옮기면서(출생 5년 추계: 학습 1980–2020, 검증 2021–2025), 코로나 시기인 2020년이 검증에서 학습 구간으로 넘어가며 예측 결과가 달라지는 것을 확인
- 업무 흐름을 정리한 보고서가 계기가 되어 부서 연구회에서 **단독 발표**
